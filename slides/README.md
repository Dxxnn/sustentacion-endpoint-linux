# Slides

Archivo principal:

- `sustentacion_primera.md`: borrador en formato Marp/Markdown exportable a PPTX.

Exportacion sugerida si tienes Marp CLI:

```bash
npx @marp-team/marp-cli sustentacion_primera.md --pptx --allow-local-files
```

Si usas PowerPoint o Google Slides, puedes importar el contenido manualmente siguiendo `docs/presentation_structure.md`. Mantén las diapositivas con poco texto y usa las capturas indicadas en `docs/screenshot_checklist.md`.
